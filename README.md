# Alphalete Athletics — Shopify rebuild

Theme code for `dev-alphaleteathletics.myshopify.com`, replicating https://alphaleteathletics.com/.

- **Base theme:** Dawn v16.0.0 (unmodified in the first commit)
- **Custom files:** everything we add is prefixed `vk-` (`sections/vk-*.liquid`, `snippets/vk-*.liquid`, `assets/vk-*.css`, `assets/vk-*.js`)
- **Workflow:** GitHub is the source of truth; push to an unpublished development theme with the Shopify CLI. Never push to the live theme without approval.
